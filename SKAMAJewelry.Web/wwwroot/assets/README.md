# Recursos de SKAMA Jewelry

Esta carpeta contiene recursos del prototipo frontend.

- `css`: tokens de diseño, temas, reglas base, componentes y utilidades.
- `js`: módulos de interacción del navegador para el comportamiento simulado de la interfaz.
- `images`: imágenes de productos, colecciones y contenido editorial.
- `icons`: iconos personalizados.
- `fonts`: fuentes de marca.
- `themes`: ajustes específicos de tema.
- `utilities`: utilidades frontend generadas o neutrales frente a proveedores.
